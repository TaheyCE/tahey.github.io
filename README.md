## GitHub Pages
1. Create a repository, e.g. `portfolio`.
2. Upload the files and the `assets` folder.
3. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Save.

## Personalize before publishing
Search `index.html` for `YOUR_` and replace:
- `YOUR_EMAIL@example.com`
- `YOUR_USERNAME`

Replace the placeholder publication, project, certificate and GIS links with your real material.

### Profile photo
Put your photo at:
`assets/profile.jpg`

Recommended: JPG, portrait orientation, at least 800×1000 px.

### CV
Put your PDF at:
`assets/Tahey_Bin_Mainur_CV.pdf`

### GIS maps
For each map card, replace the placeholder with an exported map image or link to your ArcGIS/WebGIS/StoryMap project.

### Publications
Replace the placeholder publication with your actual paper title, authors, journal, year and DOI/link.
